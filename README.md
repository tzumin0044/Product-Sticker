# Product-Sticker

品規貼標籤列印系統

## 適用系列
- 風間、森森系列
- 乾香菇系列
- 鼎泰豐系列

---

## 規格需求與業務邏輯

### 鼎泰豐
- **採收日限制**：
  - 限制僅能選擇**當日往前推 7 日**內之日期（即 `[當日 - 7日, 當日]`）。
  - 超出範圍之其他日期**一律反灰（不可選取）**。
  - **目的**：避免日期選取異常，導致標籤印錯數字。
  - **預設計算**：採收日預設為進貨日 - 1 天。

### 乾香菇系列
- **效期計算**：
  - 依據包裝日期與保存期限（年/月/天）自動推算有效日期。
  - 製造日算第一天（結果扣除 1 天）。

### 風間、森森系列
- 支援預設品項點擊加入、手動單筆/批次新增品項、出貨日期設定。
